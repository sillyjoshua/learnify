# Learnify

Learnify is a free coding-learning app prototype. No subscriptions, paid tiers, streak pressure, or paid XP boosts.

## Run

This repository currently contains a browser-based prototype. Open `index.html` in a modern browser. Progress is saved locally in that browser using localStorage; it is not yet a multi-device account service.

## Included

- Light, responsive interface
- Beginner lessons for JavaScript, Python, and HTML/CSS
- Practice editor for JavaScript with a time-limited worker
- XP and lesson completion stored locally
- No payments or streak-loss mechanics

## Status

**Early alpha / prototype.** This is not a production-ready desktop installer. Account sync, a secure server-backed leaderboard, multi-language sandboxing, and signed installers are not included in this browser prototype yet.
